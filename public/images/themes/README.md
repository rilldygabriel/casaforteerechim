# Natural e amarelo

Decorative assets generated with the built-in image generation tool on 2026-09-28, then encoded as WebP with sharp (quality 72). No text, products or branding from the supplied advertisement were copied. CSS loads only the matching desktop or mobile background when this optional theme is selected.

- `natural-stone.webp`: desktop, 1536 × 1024, approximately 93 KiB.
- `natural-stone-mobile.webp`: mobile, 768 × 1152, approximately 28 KiB.

Generation brief: photorealistic warm ivory limestone/plaster wall, fine mottled stone texture, muted olive foliage entering only at the left and right edges, soft natural light and shadows, a clean bright center for readable content; no text, logos, products, UI, horizon or furniture. The mobile version uses portrait framing with narrower foliage margins. Black typography and yellow buttons are rendered in CSS, not baked into the images.
